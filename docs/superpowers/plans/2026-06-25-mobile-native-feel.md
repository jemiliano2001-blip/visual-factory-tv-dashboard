# Mobile Native Feel — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development` (recommended) or `superpowers:executing-plans` to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Fix 5 critical mobile UX regressions and add native-feel interactions: bottom sheets for modal + filter, proper touch targets, hidden scrollbars, readable badges, haptic feedback on mic.

**Architecture:** Six sequential tasks, lowest to highest risk. Base scaffolding (Task 1) enables all later tasks. Style fixes (Tasks 2–3) are trivial and independent. Component refactors (Tasks 4–5) share the Drawer primitive from Task 1. Task 6 is a structured QA pass.

**Tech Stack:** React 18, Tailwind v4, shadcn/ui (Radix), Vaul (via `npx shadcn@latest add drawer`), Framer Motion, TypeScript

## Global Constraints

- UI copy: Spanish only — any new strings must be in Spanish
- No test runner — `npm run lint` (`tsc --noEmit`) is the only automated gate
- TV/desktop behavior must be unchanged — all changes are either mobile-only or purely additive
- `useMobile()` is at `src/hooks/useMobile.ts` — returns `boolean`, `true` when viewport ≤767px — use it, never inline a media query
- Import Drawer from `./ui/drawer` (shadcn-generated) — never import vaul directly
- `md` breakpoint = 768px — consistent throughout codebase
